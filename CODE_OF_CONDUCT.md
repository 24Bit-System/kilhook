# Code of conduct

We want kilhook to be a welcoming project. Everyone participating — in issues,
pull requests, reviews and discussions — is expected to be respectful.

## Expected behaviour

- Assume good intent and give constructive feedback.
- Critique code and ideas, not people.
- Accept that maintainers may decline a change for scope reasons. kilhook has a
  deliberately narrow v1 scope documented in `project.md`.
- Respect that this is a volunteer effort; response times are best-effort.

## Unacceptable behaviour

Harassment, personal attacks, slurs, discriminatory remarks, deliberate
intimidation, publishing someone's private information, and sustained disruption
of discussions are not tolerated. This applies in all project spaces.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers
privately at [info@24bitsystem.com](mailto:info@24bitsystem.com). Reports are
handled confidentially. Maintainers may remove comments, close threads, or
block participants who violate these rules, with or without prior warning
depending on severity.

## Scope

This code of conduct applies to all project spaces and to individuals
representing the project in public.
